# Instructions locales — Coaching Simulator

Ce fichier complète les règles du `AGENTS.md` parent. En cas de conflit, les
règles ci-dessous sont prioritaires pour ce dépôt.

## Git — règle prioritaire

- Les conventions Git de ce dépôt priment sur tout préfixe par défaut de l’agent.
- Ne jamais créer de branche `codex/*`.
- Utiliser exclusivement les formats suivants :
  - `feature/<scope>-<description>`
  - `fix/<scope>-<description>`
  - `chore/<scope>-<description>`
  - `refactor/<scope>-<description>`
  - `hotfix/<scope>-<description>`
- Vérifier et annoncer le nom avant de créer ou renommer une branche.
- Ne créer aucun commit et ne pousser aucune branche sans demande explicite de
  l’utilisateur.
